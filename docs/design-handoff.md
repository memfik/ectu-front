# ЕСТУ (QMobile): редизайн. Передача фронтенду

Макеты нового интерфейса ЕСТУ (техучёт) для компании **QMobile**. Это **готовый HTML-дизайн**, который нужно перенести в рабочий фронтенд на **Next.js**. Макеты статичные: кнопки и формы не работают, поведение описано ниже.

---

## 1. Как смотреть

1. Распаковать архив.
2. Открыть **`00-Меню.html`** в Chrome. Это оглавление всех разделов.
3. У каждого раздела 2 кнопки:
   - **Компьютер**: макет 1920 px;
   - **Телефон**: те же экраны в ширину телефона (390 px).
4. Справа сверху в меню **«Светлая тема →»**.
5. 3D-каталог оборудования: **`3D-оборудование/3D-оборудование.html`**, один файл, работает без интернета.

> Файлы тяжёлые (5–9 МБ): картинки и шрифт встроены внутрь. Открывайте по одному.

Каждый файл раздела — это **вертикальная лента экранов**: сверху подпись группы («1. Список узлов», «2. Фильтр»…), под ней экраны: список, карточки, карта, паспорт, вкладки, все окна (создание, редактирование, удаление с причиной, фильтр, отчёт, галерея и т.д.).

## 3. Дизайн-система

### Цвета (тёмная тема, основная)
| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#0a0b0e` | фон страницы |
| `--glass` | `rgba(20,22,27,.72)` + `backdrop-filter: blur(18px)` | карточки |
| `--line` | `rgba(255,255,255,.09)` | рамки, разделители |
| `--text` | `#eef1f6` | основной текст |
| `--muted` | `#8c919b` | вторичный текст |
| `--accent` | `#085eff` | бренд QMobile, кнопки, выбранное |
| `--accent-dark` | `#001a9f` | градиенты |
| статусы | зелёный `#2bd463` · оранжевый `#ff9f1a` · красный `#ff3b3b` · синий `#4f8dff` | работает / нет линка / авария / резерв |

Оранжевого бренд-цвета больше нет, бренд только синий.

### Светлая тема (стиль iOS)
`--bg #f2f2f7`, карточки `#ffffff` без рамки с тенью `0 1px 3px rgba(0,0,0,.06)`, текст `#1c1c1e`, вторичный `#6e6e73`, разделители `rgba(60,60,67,.12)`, поиск `rgba(118,118,128,.12)`. Цвета статусов iOS: `#248a3d` / `#c93400` / `#d70015`.

### Типографика и иконки
- Шрифт **Inter** (400/500/600/700), цифры `font-variant-numeric: tabular-nums`.
- Иконки **lucide** (`lucide-react`), stroke 1.75.
- Радиусы: карточки 24 px, поля 12 px, кнопки и чипы 999 px.

### Сетка
- Без сайдбара. Шапка: логотип · 6 групп меню (Сеть, Оборудование, Линии и сооружения, Клиенты, Сервисы, Аналитика) с мега-меню · поиск ⌘K · уведомления · настройки · профиль.
- Страницы на всю ширину, отступ 56 px. Паспорт: слева паспорт, в центре визуал (3D / панель / схема / карта / фото), справа узел связи, комплектация, ответственный. Ниже вкладки разделов.

### Адаптив (телефон, < 1280 px)
- Меню прячется в бургер ☰ (экран меню — `Телефон/01-Шапка-и-меню.html`).
- Колонки встают в одну, KPI в 2 колонки, таблицы листаются по горизонтали внутри своего блока.
- Окна открываются на весь экран.

## 5. Данные

Поля и названия взяты **из реальной БД ЕСТУ** (дамп prod от 07.10.2026). Главные таблицы:

| Раздел | Таблица |
|---|---|
| Узлы связи | `nodes` |
| СПД (коммутаторы / маршрутизаторы) | `spd_equipments`, порты — `spd_equipment_ports` |
| SDH / DWDM | `sdhs`, `dwdms` (иерархия шасси → платы по `parent_id`) |
| PDH, РРЛ, радиомосты | `pdhs`, `rrl_equipments`, `radio_bridge_equipments` |
| БШД | `bhd_wimaxes`, `bhd_ltes`, `bhd_wlls` |
| ИБП, ГЭУ | `ibps`, `geys` |
| АТС | `phone_stations`, `phone_number_capacities` |
| ВОЛС, КЛС, КК, ODF, АМС | `bols`, `kls`, `kks`, `odfs`, `ams` |
| OneWeb, VSAT | `one_webs`, `oneweb_*`, `triple_s` |

**Ядро сети** (43) — перенос вкладки из KTicket. Схема берётся из `kticket-back/config/core_map.php`, трафик из Orion (API `/api/monitoring/orion/core/*`), раскладку узлов можно перетаскивать и сохранять (`core_map_positions`).

⚠️ В макетах ФИО, телефоны и почты — **примеры**, IP-адреса скрыты (`x.x`). В рабочей версии брать из API.

## 6. 3D

- Библиотека: **Three.js** (в Next.js: `three` + `@react-three/fiber` + `@react-three/drei` или чистый three в `useEffect`). Компоненты с WebGL подключать через `dynamic(..., { ssr: false })`.
- Каталог `3D-оборудование.html` — рабочий прототип, логику можно брать оттуда:
  - **генератор моделей по типу корпуса** (стойка, шасси, антенна, CPE, ИБП, ГЭУ, шкаф АТС, ODF, узел связи, АМС);
  - **порты строятся из `spd_equipment_ports`:** тип, скорость, admin/oper status, описание; цвет патч-корда зависит от описания;
  - **2 вида:** «3D-модель» и «Передняя панель» с выносками;
  - **наведение:** карточка порта с пунктиром. **Клик:** редактор состояния (Работает / Нет линка / Выключен / Свободен / Резерв / Неисправен, описание, клиент, примечание), журнал изменений;
  - **«Полная / лёгкий режим»:** тени, мигание, мелкие детали. В лёгком режиме рендер только при движении камеры;
  - **«Окружение»:** стойка 42U с соседями; у узла связи контейнер, мачта, забор.
- В прототипе изменения портов хранятся в `localStorage`. В проде нужен API на запись.
